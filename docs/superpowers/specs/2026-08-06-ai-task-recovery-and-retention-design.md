# AI 任务恢复与保留设计

## 目标

修复直出视频因 HyperFrames 媒体元素缺少 `id` 而反复失败的问题；确保批量图文和批量视频不会被任务中心总览静默隐藏；并在失败或取消任务三天未更新后清理其数据库记录和本地工作区。

## 边界

- 不降低 HyperFrames 的校验标准，不伪造验证记录。
- 只删除状态为 `FAILED` 或 `CANCELLED` 且 `updatedAt` 已超过三天的 AI 任务。
- 本地仅删除与服务器确认候选任务编号完全相同的工作区；不碰系统素材库和已登记成果。

## 方案

1. 直出视频提示词明确要求每个定时音频、视频元素具有唯一 `id`，并要求 HyperFrames lint 无错误才可登记 lint 成功。
2. AI 任务中心总览移除前端 `12` 条截断，保留既有状态、类型、平台和关键词筛选。
3. API 向已认证执行器提供三天前的终态任务候选；执行器删除匹配本地工作区后回传确认，API 复核状态和更新时间后删除任务。关联尝试、快照、输出和通知依赖现有级联关系删除。

## 验证

- 单测覆盖 HyperFrames 合规提示、总览不截断和终态清理的候选/复核条件。
- 对当前 W9 工作区补齐技术 `id` 后执行真实 lint、render 和本地验证；仅全部通过后恢复上传。
