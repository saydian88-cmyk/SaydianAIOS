# 批量图文对外内容禁用内部词设计

## 目标

批量图文任务的默认要求明确禁止内部制作信息出现在最终图片、标题、标签和发布文案中；员工审核页只展示 Skill 的真实回传结果。

## 范围

- 仅修改批量图文任务的默认要求和交给图文 Skill 的执行提示。
- 禁止图文类型、页数、组号、内部任务号等内部制作信息出现在任何对外内容中。
- 系统内部继续保存并展示产品、类型、页数和组号，用于分配、审核和发布管理。
- 每组审核卡片读取与该组绑定的真实图片、标题、标签和发布文案。
- 未回传的图片或文案明确显示“未回传”，不得使用占位图或本地模拟文案伪装生成成功。

## 不在本次范围

- 不增加图片文字的 OCR 自动拦截或校验。
- 不改变图文 Skill 的素材选择、创意方向或图片生成方式。
- 不处理已经创建的历史任务。

## 执行规则

默认任务要求增加一条独立且明确的对外内容规则：最终图片画面、标题、标签、发布文案不得出现图文类型、页数、组号、任务编号或其他内部制作标识；这些信息仅供系统内部使用，不能写入面向用户的内容。

Skill 每组回传的页面、标题、标签和发布文案必须按组号保存。员工端按组读取这些回传数据；没有对应回传时，只显示缺失状态和重新执行/退回入口。

## 验收

新建批量图文任务的自动任务要求包含该规则，且规则与现有的真实素材限制、交付内容要求不重复、不冲突。审核页不再显示统一占位图和模拟标题、标签、文案；每组只显示真实回传或明确的未回传状态。
